MIYONOS UNIVERSAL BROWSER INSTALLER

This package works on Windows, macOS, and Linux. It does not install software
on the computer.

1. Extract this complete ZIP file.
2. Double-click "Open Miyonos Installer.html".
3. On the Miyoo, enable:
   Apps > Tweaks > Network > HTTP: Web-based file sync
4. Follow the guide in the opened browser page.
5. In the Miyoo file server, log in with admin / admin, open App, and upload
   the complete Miyonos folder included beside the HTML guide.
6. Disable HTTP file sync when finished and open Apps > Miyonos.

For an update, repeat the upload and allow existing application files to be
replaced. The included Miyonos folder has no data directory, so settings, logs,
diagnostics, and artwork are preserved. Do not run Miyonos while uploading.

Use network services only on a trusted private network. Change the default
OnionOS HTTP password if the service will be used regularly.
