Guided installation

Connect to your Miyoo

release
1

Enable the OnionOS HTTP file server

On the Miyoo, open the following setting, enable the service, and exit Tweaks so the server starts.

Apps → Tweaks → Network → HTTP: Web-based file sync
2

Open the Miyoo file server

The IP address is shown at the top of the Network screen. Your computer and Miyoo must use the same trusted Wi-Fi.

The Miyoo file server was opened in a new tab. Keep this guide open so you can follow the final step.
3

Log in and upload the Miyonos folder

In the Miyoo file server, log in, open App, choose upload, and select the complete Miyonos folder located beside this HTML file. Approve merge or overwrite when updating an existing installation.

Miyonos

Upload this included folder into the Miyoo App directory.

Finish on the Miyoo

Close the file server tab, disable HTTP file sync when you are done, and open Apps → Miyonos. A first installation may require an Apps refresh or a MainUI restart.

Updating an existing installation

Repeat the same upload and allow existing app files to be replaced. The release folder contains no data directory, so settings, logs, diagnostics, and cached artwork remain in place. Do not run Miyonos while uploading an update.

Why is folder selection still required?

Browsers are not allowed to choose local files or bypass a device login on your behalf. This protects your computer and local network. The transfer itself is handled by the website running on the Miyoo, which is why no computer-specific installer is needed.
